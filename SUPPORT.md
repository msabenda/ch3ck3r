# Support

## Questions and Usage Help

Use GitHub Discussions for setup questions, rule behavior, integration ideas, and general usage once Discussions is enabled for the repository.

Use GitHub Issues for reproducible bugs and scoped feature requests. Include the extension version, VS Code version, operating system, affected language, a minimal redacted sample, expected result, and actual result.

## Security Reports

Do not post vulnerabilities or real secrets publicly. Follow [`SECURITY.md`](SECURITY.md).

## Limitations

Ch3ck3r is maintained as an open-source project without guaranteed response times or commercial support. Findings are heuristic and require human review.
